# oss-radar

A weekly directory of **new and fast-rising open-source repositories**, with the **SF Bay Area** and the **rest of the US** highlighted. It updates itself every Monday.

- **🔥 Gaining traction:** repos up to $traction_months months old, ranked by stars gained this week (*Biggest gains*) and by growth rate (*Fastest growing*).
- **🆕 New & notable:** repos created in the last $new_window_days days that already have traction: $bar_us+ stars for owners in the US, $bar_other+ elsewhere.

Every listed repo has been checked by Claude to make sure it is real software that solves a specific problem.
