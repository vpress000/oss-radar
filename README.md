# oss-radar

A weekly directory of **new and fast-rising open-source repositories**, with the **SF Bay Area** and the **rest of the US** highlighted. It updates itself every Monday.

- **🔥 Gaining traction:** repos up to 12 months old, ranked by stars gained this week (*Biggest gains*) and by growth rate (*Fastest growing*).
- **🆕 New & notable:** repos created in the last 30 days that already have traction: 50+ stars for owners in the US, 250+ elsewhere.

Every listed repo has been checked by Claude to make sure it is real software that solves a specific problem.

## How it works

1. Every Monday a GitHub Action searches GitHub for repos created in the last 30 days, and for repos up to 12 months old with at least 1,000 stars.
2. Each repo is placed by the location on its owner's GitHub profile: SF Bay Area, Rest of US, Outside US, or Location unknown.
3. Free rules drop forks, archived repos, mirrors, templates, profile repos, GitHub Pages sites and likely star farms.
4. Claude reads each remaining repo's description and README. It keeps real tools, libraries, apps and research, and drops tutorials, link lists, demos and spam. Reviews run overnight, up to 300 a night.
5. Star counts are recorded every week. Repos stop being tracked when they turn 12 months old and stay in the monthly lists.

**Notes**

- The "What it solves" lines are written by AI and may be imperfect.
- Locations are shown as their owners wrote them on GitHub.
- Want a repo added or removed? [Open an issue](https://github.com/vpress000/oss-radar/issues/new).
